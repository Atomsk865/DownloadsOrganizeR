📁 SortNStore

Automated File Organization Made Simple

⚙️ System Requirements

  • Windows 10/11 or Windows Server 2016+
  • Administrator privileges
  • Internet connection
  • Python 3.8+ (installer will help if not installed)

🚀 Quick Install (Recommended)

Method 1: One-Command Install

  1. Right-click PowerShell and select "Run as Administrator"
  2. Copy and paste this command:
    Set-ExecutionPolicy Bypass -Scope Process -Force; ` Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Atomsk865/DownloadsOrganizeR/main/Install-DownloadsOrganizeR.ps1" -OutFile "$env:TEMP\Install-DownloadsOrganizeR.ps1"; ` & "$env:TEMP\Install-DownloadsOrganizeR.ps1"
  3. Press Enter and follow the installation wizard

Method 2: Download and Run

Download the installer and run it:

📥 Download PowerShell Installer 📥 Download Batch Installer

After downloading, right-click the file and select "Run as Administrator"

📦 What Gets Installed

  • ✅ Python 3.8+ (if not already installed)
  • ✅ Latest version from GitHub
  • ✅ All required dependencies
  • ✅ Windows service (auto-starts on boot)
  • ✅ Health monitoring (checks every 5 minutes)
  • ✅ Desktop shortcut for dashboard

🎯 After Installation

  1. Click the "DownloadsOrganizeR Dashboard" desktop shortcut
  2. Dashboard opens in your browser at http://localhost:5000
  3. Login with default credentials:
    Username: admin Password: change_this_password
  4. Change your password in Settings
  5. Configure watch folders and file categories
💡 Tip: The organizer service runs automatically in the background. Files in your Downloads folder will be automatically organized into categories like Images, Documents, Videos, etc.

❓ Troubleshooting

Python Not Found

Download Python from python.org and make sure to check "Add Python to PATH" during installation.

Permission Denied

Make sure you're running PowerShell or the installer as Administrator. Right-click and select "Run as Administrator".

Service Won't Start

Check logs at C:\DownloadsOrganizeR\service-logs\ for error details.
