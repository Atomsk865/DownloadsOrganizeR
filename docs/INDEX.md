## Documentation Conventions

### File Naming
- Use uppercase with underscores: `EXAMPLE_FILE_NAME.md`
- Descriptive names that indicate content
- Abbreviations used: `QUICKSTART`, `GUIDE`, `ROADMAP`, `ARCHITECTURE`, `SUMMARY`

### Structure
- H1 heading at top
- Quick navigation/TL;DR early
- Table of contents for long documents
- Code examples where relevant
- Links to related documentation

### Link Format
- Use relative paths: `[Link](../category/FILE.md)`
- Link back to main docs/INDEX.md
- Link to root README for home

When adding new documentation:
